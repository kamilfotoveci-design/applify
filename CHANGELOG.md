# Changelog

## 1.1.6
- Background widget refresh after returning from add-ons, playback or dialogs.
- Active hub widgets refresh every 60 seconds without reloading the skin.
- Manual widget refresh no longer needs a full skin reload.
- Left/Right on the top bar switches hubs without pressing OK.
- Separate widget lists and hero-row selection are kept for each hub.
- Watched badges when the content add-on provides watch status.
- Seek-step and seek-offset feedback.
- Option to hide Watch Now.
- Removing a row creates an Empty Slot; hiding stays a separate action.
- Simplified XML conditions; corrected hidden-hub navigation.

## 1.1.5
- Fixed the Add-on error when opening a widget row in Configure Widgets.
- The repository builder now rejects this helper-shadowing error before publishing.

## 1.1.4
- Left/Right moves focus on the top bar; OK selects the tab.

## 1.1.3
- Power icon beside Settings opens Kodi Power Options.
- Right from a row's See All returns to its first card.

## 1.1.2
- Corrected ranked card numbers in custom hubs.
- English-only skin language catalog.
- Browsable source code.

## 1.1.1
- Three optional custom hubs, eight widget rows each, up to six submenu links per hub.
- Native Live TV / Radio destinations.
- Full menu/widget backups and on-demand repository diagnostics.
- Capability-gated Reboot to Android on CoreELEC.

## 1.0.0
- Initial release based on Estuary and Orchard TV.

Older per-release notes are kept in [docs/archive](docs/archive).
