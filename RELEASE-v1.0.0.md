# Applify v1.0.0

The first Applify release brings an Apple TV-inspired interface to Kodi.

- Cinematic home screens and configurable widgets.
- Movie and TV information, search and playback controls.
- Bundled SF Pro Display typography and fallback fonts.
- Installation and updates through Applify Repository.

Add this project's published GitHub Pages URL as a source in Kodi's File manager,
install repository.applify-1.0.0.zip, then install Applify from Applify Repository.

Targets Kodi 21. Full Kodi/CoreELEC runtime and Kodi 22 compatibility have not
been verified in the build environment. Independent project, not affiliated with Apple.
