# Pyrus Skin v1.1.3

By kamilwhoo. Apple TV-inspired Kodi skin with configurable widgets and Player Info.

Install and update through https://kamilfotoveci-design.github.io/applify/.
The technical ID remains skin.applify so existing settings and updates continue.

This update adds a Power button beside Settings on the home bar. It opens
Kodi Power Options; Reboot appears when the device supports it. English is
the only included skin language catalog. See RELEASE-1.1.3.txt
for changes and device-dependent limitations. Source text is browsable at
https://github.com/kamilfotoveci-design/applify/tree/main/source/skin.applify.
