# Browsable Pyrus Skin source

`skin.applify/` mirrors the readable files of the installable ZIP in the repository root: Kodi XML, Python, the English catalog, playlists, manifests, release notes and licences.

Binary artwork and fonts are distributed only in the ZIP and are not duplicated here. The mirrored files match the ZIP byte for byte.

For feedback or a code change, open an issue or pull request. The maintainer packages a matching ZIP before publishing a new version.
