# Browsable Pyrus Skin source

`skin.applify/` mirrors the readable files in the 1.1.3 installable ZIP: Kodi XML,
Python, the English catalog, playlists, manifests, release notes and licenses.

Binary artwork and fonts are distributed in `skin.applify-1.1.3.zip`. They are not
duplicated here. The repository builder compares every mirrored file byte for byte
with the ZIP before publishing, so the code visible on GitHub matches the release.

For feedback or a code change, open an issue or pull request against these files.
The maintainer must package a matching ZIP before publishing a new version.
