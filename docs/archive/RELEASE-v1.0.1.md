# Pyrus Skin v1.0.1

By **kamilwhoo**. Previously named Applify.

## Changes

- New Pyrus Skin name and pear icon.
- Four real home-screen captures, supplied by the maintainer, included in Kodi metadata, the source website gallery and README.
- Unified neutral dialog surfaces and focus materials shared across settings, selection lists, confirmations, text views, keyboard/numeric dialogs, add-on controls and other windows that use the common components.
- Reworked add-on information: compact icon, separate description/metadata areas, no empty screenshot placeholders and evenly centered circular action buttons.
- Aligned settings typography, 64 px generated setting rows, spacing, switches and category navigation.
- Corrected publication of artwork at the paths declared by the add-on, fixing missing repository icons and preparing screenshot support.
- Updated skin, repository and website descriptions to reflect maintainer testing on Kodi 22 and the detailed Player Info tabs.
- Kept the existing add-on IDs and source URL to preserve update and settings continuity.

## Compatibility and validation

The maintainer has tested the skin on Kodi 22. The 1.0.1 package has been checked statically for XML/Python syntax, native control/action preservation, asset/font references, archive integrity and repository metadata/checksums. This new visual update still needs a final on-device pass in Kodi 22 before its release announcement.

Player Info displays values reported by Kodi and the playback pipeline. Available fields vary by build, hardware and content.
